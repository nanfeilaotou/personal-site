## Logo 处理

现有 15 个 SVG 的 SHA256 均与精修前一致，没有重下载，也没有改图形路径或 viewBox。使用固定标识槽统一与文字的垂直对齐，默认桌面标识槽 36px，并针对横向轮廓、细线条、复杂图形做 CSS 比例校准，不裁切、不拉伸、不增加统一圆框。

- Claude Code 在 30px 原始方形框中，实际有色高度只有约 18.75px；节点 CSS 比例设为 1.35，在默认 36px 槽内获得约 30.4px 的实际图形高度。
- DeepSeek / DSH 为横向轮廓，比例 1.25；Grok、Kimi 为 1.12；Qwen 为 1.1；LM Studio 为 1.18。
- Hermes 的复杂图形放大至 1.25；Codex 放大至 1.1，保留内部细节；ComfyUI 的实心轮廓略收至 .95。其余保持 1 或小幅校准。全部 object-fit:contain，不使用 CSS filter 去色。
- DSH：从官方仓库提取 `FishLogo`，节点同时显示产品全称；另提取 `BrandWordmark` 放在审查页核对。保留 MIT 许可并遵循官方品牌规范，只作介绍识别，不暗示官方关系。
- ZCode：从官方 `ZCodeAboutLogo.tsx` 提取独立产品 SVG，保留 Apache-2.0 许可与原始三条路径。
- Tencent WorkBuddy、Muse：已找到对应产品的官方彩色资源，未确认单色版本与复用条件，保留文字；Grok Bot：没有核对到可复用的独立产品单色标志，保留文字，不冒用 Grok / Cursor 通用图标。

现在八个模型都有图标，十个 Agent 为 **七个图标、三个名称标识**。新增资源明确使用官方 currentColor 单色实现，没有擅自把有配色的图标转白。审查页逐项显示资源、viewBox、三档尺寸、CSS 校正、来源和未解决原因。
