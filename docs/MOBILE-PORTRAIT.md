## 审查与缺陷清单

检查 320×568、360×740、375×667、390×844、430×932，全部覆盖 DPR 1 / 2。每轮 **165 帧**：DPR1 为五种尺寸各 22 个阶段，DPR2 为五种尺寸各 11 个关键阶段。共保留 **330 张修改前后截图**，包含稳定停靠与模型生成、量化、两次 AI 交接、黑白翻面、下潜、粒子成像和 Personal 接缝。

|区域|原问题|手机修复|
|---|---|---|
|全局|DOM、Canvas、说明、卡片各用屏幕百分比猜位置|共用移动端安全区域与内容矩形，测量实际顶栏、文字和底部说明高度|
|Opening / 序列|部分画布说明可能伸出窄屏；需检查字形完整性|保留 Shader、采样与字形；约束移动说明位置和章节数字构图，不改粒子聚散算法|
|Models|八节点环上间距小，标签压标题/入口|双列四行、真实字号与命中区；轨迹与标识从同一组投影点产生|
|Local AI|工具标识挤成一行，英文工作流与中文说明互压，画布旁注出屏|数值/去噪图在左、三个工具纵列在右；工作流改 2×2 中文标注；扫描标签有背景挖空；准确的精度/去噪短说明由 DOM 承载|

|网络|客户端之间重叠，VPS / REMOTE 文字相压|按可用矩形反投影到同一拓扑世界；四客户端双列、远程立方体留位，标签向两侧避让；保留翻面、扩散及原角度终态|
|账户与钱包|锚点名称、类别、立杆及 Logo 相压|五品牌分三行，账户与钱包分组；短锚点/自身引线移到标志侧边，不产生品牌互通连线|

几何结果：稳定帧 AABB 相交记录 **240 → 0**，这是跨尺寸、DPR 的重复记录，**不是 240 个独立缺陷**。原有 Local 关键画布旁注有 **20 条出屏记录**，已改为安全区内短注与 DOM 说明；优化后关键画布文字没有出屏或压住内容。还检查了真实字形目标范围、Local 方格/工作流矩形、两个线框立方体实际顶点和三张完整卡面范围。无限网格、背景线场和粒子入场数据流有意延伸到屏外，不混同于内容裁切。

## 统一布局接口

`prototype/mobile-layout.js` 是首页手机构图契约；`prototype/mobile.css` 消费其 CSS 变量。仅 `width ≤ 760 && 可视高度 > 宽度` 生效，桌面继续原分支。

- 从一个测量探针读取 `env(safe-area-inset-*)`，从真实 LENS 元素读取头部范围；`visualViewport` 仅在非缩放状态参与高度测量。
- AI 内容范围扣除真实标题高度、内部目录、注释和底部操作条。节点按实际内容高度排布并缓存；DOM 和 Canvas 共用节点投影，帧循环不重复测量每个节点。
- Global 内容范围扣除真实领域导航和各说明面板高度；相机、信号、品牌和卡面使用同一结果。网络通过同一相机反投影，标签与真实路径不维护两份坐标。
- 图标、名称、主卡、侧卡及命中区保持原比例；招行源图 CSS 宽度仍不超过原 `maxWidth=290.5`（对应 581×373 源图的 DPR2 像素预算）。
- 特别短的可视高度（含安全区扣除）进入紧凑模式：压缩重复简介与面板排布，名称维持 12px、重要目标维持 44px，不整体缩放页面或隐藏品牌。
- 可视高度与布局滚动口不同时，track 用 `TOTAL * UNIT + innerHeight` 补偿，确保仍可到达完整的 15.68 屏末尾。安全区探针固定在原点，不增加文档滚动长度。

另有一个必要的通用缓存修复：Global 品牌离场时清理显隐/命中缓存，避免回到完全相同进度时标志仍隐藏、无法聚焦。首次桌面构图不变；20 个随机暂停点正反向复用验证显示与命中状态。

## 性能与限制

手机视口模拟 390×844 / DPR2：稳定停留与切卡的 rAF 间隔 p95 均约 **4.3ms**，切卡稳态采样没有 >50ms 长任务；静止卡面新增绘制 **0**。它反映本机 240Hz 回调环境，**不能称为手机 240fps**。

重复 Resize 后仍为两个原 WebGL Context、3 次纹理上传、16 个 Global 品牌和 3 个卡片 DOM；卡片顶点缓冲约 1.02MB、纹理未压缩字节记录约 5.87MB，均不是完整 GPU 内存测量。GC 后 JS 堆的小幅变化与原始记录一并保留，不据一次采样宣称已证明长期无泄漏。

冷启动仍有一次性长任务（独立样本最大约 230ms；基线独立样本约 130ms）。另一次同浏览器 CPU / WebGL 调用采样主要落在原有初始化、加载、纹理上传和程序链接路径；缓存条件不同，不能据此宣称冷启动变快，也未为缩短该路径重写已验收算法。此项作为后续实机性能复核点。

尚待人工/实机：

- iPhone Safari、Android Chrome 的真实字体、动态地址栏、系统手势区和低端 GPU 表现。
- 横屏只验证旋转恢复、无重复初始化和内容基本可达，未完成横屏美术重排。
- 招行卡源图仍为低分辨率素材，不虚构高清细节；需要更大展示时应提供更高清的可信来源。
- 当前未检测到剩余的指定竖屏稳定布局遮挡/裁切；用户已完成初步视觉验收；真实手机上的留白、运动节奏和系统行为继续收集反馈。
